# CL-DIY

CL-DIY is a do-it-yourself editor for causal loop diagrams (CLDs). It runs
as a single, self-contained HTML page: no server, no install, no account.
Open the file in a browser, build or import a diagram, and export it as an
image or a JSON file.

## Quick start

1. Download [`CL-DIY.html`](CL-DIY.html).
2. Open it in any modern browser (Chrome, Firefox, Safari, Edge).
3. Start adding variables, or upload an existing diagram (`.json` or a
   Vensim `.xmile` export).

Everything happens in your browser. Nothing is uploaded anywhere.

## Features

- **Variables and links:** add, rename, merge and delete variables; add
  causal links and mark each one as positive (+) or negative (-).
- **Subsystems:** colour-code variables by group (for example individual,
  community, system). Subsystems can be renamed, recoloured, added and removed.
- **Feedback loops:** trace a loop by clicking its variables in order, save
  it as reinforcing (R) or balancing (B), and highlight one or several
  loops at once. CL-DIY checks that every saved loop is a real cycle.
- **Layout:** drag variables anywhere. Nodes stay where you put them; turn
  on the layout springs when you want the diagram to tidy itself.
- **Undo, search and a change log** of every edit. "Comment on edits" is
  on by default: each change (deleting or merging variables, adding links,
  ...) asks for an optional note on why it was made. Turn it off from the
  prompt or the button; you can also comment on any entry in the log later.
  The change log, with its comments, downloads as a CSV file.
- **Import and export:**
  - One **Save** button, three formats: a web page (`.html`, the editor
    with your diagram inside, ready to open and keep editing), JSON
    (positions, subsystems, loops and the change log included; upload it
    again later) or Vensim XMILE (variables and links only).
  - Upload a Vensim `.xmile` file directly.
  - Export the whole diagram, or individual loops, as a PNG with a white or
    transparent background, with or without the +/- signs.

## Building the page yourself

`CL-DIY.html` is generated by `render.py` from the files in `templates/`.
You only need this if you want to change the code, or render a diagram
straight into a page from the command line.

Requirements: Python 3.9+ and [NumPy](https://numpy.org).

```sh
python3 render.py                                # blank editor -> cld.html
python3 render.py my-diagram.json out.html       # an edited JSON export
python3 render.py my-diagram.xmile out.html      # a Vensim XMILE export
```

### Vensim files

CL-DIY reads Vensim XMILE exports of causal loop diagrams: every variable
and the causal parents listed in its `A FUNCTION OF(...)` equation. It does
not read stock-and-flow simulation models.

When two diagrams are merged into one Vensim file, Vensim renames the
colliding copy's variables with a `_0` suffix. If that copy is not real
content, drop it with:

```sh
python3 render.py my-diagram.xmile out.html --drop-suffix _0
```

When you upload such a file in the browser instead, CL-DIY detects it and
asks whether to drop the duplicate.

## Project layout

| Path | What it is |
|---|---|
| `CL-DIY.html` | The ready-to-use editor (generated, blank) |
| `render.py` | Builds the HTML page from a diagram and the templates |
| `templates/` | The page itself: `page.html`, `style.css`, `app.js` |
| `sd.py` | Parses Vensim XMILE files into a graph |
| `layout.py` | Force-directed layout for imported XMILE diagrams |
| `node_levels.py` | The default subsystems |
| `empty.json` | The blank starting diagram |
| `examples/example.json` | A small synthetic example diagram (open it with "Upload graph") |
| `fonts/` | Embedded fonts (Public Sans, Fraunces) and their licences |
